Let me walk you through our preprocessing pipeline. First, we apply a notch filter at 60 Hertz to remove line noise. Second, we bandpass filter the data between 0.1 and 40 Hertz. Third, we average reference the signals. Fourth, we use ICA to remove ocular artifacts. Fifth, we extract epochs from negative 0.2 to 2.0 seconds, with a baseline correction applied from negative 0.2 to 0 seconds. Sixth, we set a rejection threshold of 150 microvolts peak-to-peak, and automatically drop any epoch exceeding this threshold. Note that the number of epochs will vary across subjects. Seventh, each surviving epoch is tagged as either 1 for correct trials, which is code 201, or 0 for incorrect trials, which is code 200. Finally, the data is resampled to 128 Hertz after epoching.

For validation, we use GroupKFold-by-subject cross-validation. With approximately 256 subjects and 5 splits, each fold holds out roughly one-fifth of the subjects—that's about 51 subjects—as the test set, and trains on the rest.
